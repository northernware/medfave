# Patient portal: a full-width web app, Documents list, white emergency card

Opened: 2026-10-03 22:36 PHT

## What
- **Full width.** The portal no longer passes `narrow` to the shell, so it uses the window like the doctor's pages. The form pages (Request a visit, My details, My family, Add a clinic, Emergency card) cap themselves at `max-w-4xl`.
- **Home has a side panel**: Your clinic (address, Call), Documents (the latest four, See all), Family (who's showing, Manage). Visits, requests and past visits stay in the main column.
- **Person pills under the heading.** They're `components/person-switch.tsx`, placed by each page (Home, Request a visit, Documents, My details) instead of above everything in the layout.
- **Documents works.** `/portal/documents` had no page, only `[id]`, so the sidebar link was a 404. It now lists what was shared, with doctor and date.
- **Emergency card is always white**, with fixed brand colours (new `--brand-gray`), like a card you carry. It was `bg-canvas` and themed greys, so it went dark in dark mode.
- **Breadcrumbs** inside the portal say "Documents" / "Document" and "Emergency card". The portal's own sections show none, as the doctor's sections don't.

## Why
Owner: the patient web should feel like the clinic's web app; Documents was broken; the pills belong under the heading; the emergency card shouldn't change colour.

## Tested
- `tsc --noEmit` and `eslint` clean. On the local dev server as the demo patient, dark, 1280 px: Home, Documents and the emergency card checked. Light mode and phone width not checked.
