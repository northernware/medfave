# Permanent deletes: a quiet line, a proper dialog, a typed phrase each

Opened: 2026-10-02 17:57 PHT

## What
- `DangerZone` on the page is now one quiet right-aligned line ("🗑 Delete this appointment") instead of a bordered card, so a page doesn't end on a block about deleting.
- The dialog was rebuilt: a tinted round warning icon beside a display-font heading and the warning; the phrase field full width with a focus ring and a hint that changes to "That matches."; and a footer bar with **Cancel** then the filled red button. It closes on Escape and on a click outside.
- Deleting a **patient registration** and a **household** now ask for a typed phrase too (`delete registration`, `delete household`), checked on the server before anything is read or removed; a refusal reuses each page's existing message.

## Why
The user asked for the delete UI, including the modal, to be fixed, and for the other permanent deletes to match the appointment one.
