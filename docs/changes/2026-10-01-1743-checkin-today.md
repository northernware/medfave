# Check in and start only on the visit's day

Opened: 2026-10-01 17:43 PHT

**What:**
- `changeAppointmentStatus` refuses CHECKED_IN and IN_CONSULTATION unless the visit is today by the clinic's clock (`reason: "not-today"`; `isClinicToday` in `lib/booking.ts`). `startConsultation` checks the same. The web shows "Not today's visit. … Nothing was changed." on the appointment page (doctor and desk); the API answers 409.
- The schedule panel shows Check in / Start only when the day shown is today.
- Data: Ramon Dela Cruz's 2 Oct 8:00 visit, checked in by mistake from the panel on 1 Oct, put back to Confirmed with no arrival time.

**Why:** the user checked someone in for tomorrow from the panel with one click.

**Tested:** `tsc`, eslint; checking in the 2 Oct visit through the API on 1 Oct returns 409 and leaves it Confirmed.

**Not done / next:** no confirmation or undo for a same-day check-in (a wrong one can be cancelled or marked no-show).
