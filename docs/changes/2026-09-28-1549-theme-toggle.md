# Light / dark / match-device theme switch

Opened: 2026-09-28 15:49 PHT · PR #16 (merged) · note written afterwards

## What
- A three-way switch (`components/theme-toggle.tsx`) in every shell: landing, sign-in, doctor, desk, manage, portal and account.
- The choice is kept in a `theme` cookie. The root layout puts `data-theme` on `<html>` and sets the browser theme colour (`generateViewport`).
- `app/globals.css` now writes each colour once as `light-dark(light, dark)`, with `color-scheme` choosing which half applies. The heart pattern image follows the same rule through selectors.

## Why
Requested: a light/dark toggle inside and outside the app.

## Tested
Server output for every cookie value; the compiled CSS; screenshots of forced themes against the opposite device setting. Not tested: clicking the switch in a live session.

## Heads-up
Add new colours to `globals.css` as `light-dark(...)`. Don't add a `prefers-color-scheme` block for a colour.
