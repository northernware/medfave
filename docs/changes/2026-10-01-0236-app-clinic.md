# Clinic settings from the app

Opened: 2026-10-01 02:36 PHT

## What
- **`lib/staff.ts`:** inviting staff moved out of `app/actions/access.ts`
  (unchanged rules) so the web and the app share it.
- **API:** `GET/PUT /api/v1/doctor/clinic-settings` (details, `sharedCharts`,
  staff and open invitations) and `POST /api/v1/doctor/staff` (invite; returns
  the code). `docs/api.md` updated.
- **Hours fix:** `GET /doctor/hours` returned an empty week for a doctor who
  never saved hours, so the app showed every day closed. It now returns the
  standard week trimmed to the clinic's, with `mineConfigured: false`.

## Why
Mobile-first, step 3 (clinic settings). The owner reported the app's hours
not loading.

## Tested
- `tsc` and `eslint` pass. With medfave-mobile's `app-clinic`, 7 checks on
  the dev server as doctor@medfave.com: the standard week shows (09:00, inside
  clinic hours) with a notice; settings load; details save (DB phone updated);
  an invitation shows its code and is listed; no sharing switch in a
  one-doctor clinic.
- The web Staff page wasn't re-run in a browser; it calls the moved code.
