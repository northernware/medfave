# One gap: 12px between sections, as from the sidebar

Opened: 2026-10-02 15:40 PHT

## What
- Every signed-in page (doctor, desk, portal, clinic settings; 42 pages) now spaces its sections and cards 12px apart. That's the page root's `space-y-3`, two-column layouts' `gap-3`, and the card stacks in those columns. It matches the 12px between the sidebar and the content (the main area's `lg:p-3`), as the Today dashboard already did. Before, pages used 16 to 24px.
- Spacing inside cards (between form fields, list rows) is unchanged.
- Loading skeletons use the same gaps, so pages don't jump when they load.

## Why
The user wants the vertical space between sections to equal the horizontal space from the sidebar.

## Tested
`tsc` and `eslint` are clean. Not compared on screen.

## Heads-up
The convention for new pages: `space-y-3` between sections, and `gap-3` between columns.
