# API for the app to catch up: carry-over, visit history, start household

Opened: 2026-10-02 04:50 PHT

## What
- `lib/carry-over.ts` (shared by Document visit and the API) and `GET /doctor/records/carry-over?patientId=`.
- `GET /doctor/appointments/:id/history` (`lib/visit-history.ts`).
- `lib/households.ts` (`startOwnHouseholdFor`, `isAdult`), shared by the web action and the new `POST /doctor/patients/:id/household`. `GET /doctor/patients/:id` adds `household.housemates` and `canStartOwn`.
- `docs/api.md` is updated, including the check-in move.

## Why
The user asked for the app to keep up with the web: follow-up pre-fill, visit history and Start their own household.

## Tested
`tsc` and `eslint` are clean. The web behaviour is unchanged: the logic moved into `lib/` as it was.
