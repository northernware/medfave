# First, middle and last name at sign-up; names tidied

Opened: 2026-10-01 12:29 PHT

**What:**
- New `lib/names.ts`: `tidyName` (collapse spaces; title-case only a name typed all lower or ALL CAPS — "dela Cruz", "McArthur", "Ma. Teresa" are kept as typed) and `withFullName` (joins firstName/middleName/lastName into `fullName`; first and last are required).
- Sign-up, Google sign-up, activation (register) and staff-invite forms ask for First / Middle (optional) / Last name (`components/name-fields.tsx`). Schemas preprocess with `withFullName`, so `fullName` is stored as before; API clients sending `fullName` alone still work (tidied).
- Desk patient names (first, middle, last, emergency contact) are tidied the same way.
- The account page still edits the full name as one field (tidied).

**Why:** the user wanted names split and correctly capitalised. Stored as typed, not ALL CAPS: capitals for printouts are a display choice.

**Tested:** `tsc`, eslint; `tidyName` / `withFullName` on "paula santos", "PAULA  SANTOS", "dela Cruz", "McArthur", "ma. teresa", "o’neil-smith", "JOSÉ", and a missing last name.

**Not done / next:** existing names in the database aren't rewritten.
