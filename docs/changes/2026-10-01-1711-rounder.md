# Rounder squircles

Opened: 2026-10-01 17:11 PHT

**What:** where the browser draws squircles, radii are 16 / 24 / 32 / 44px (sm/md/lg/xl), up from 11 / 16 / 22 / 28. Fixed a bug: `--radius-xl` was a literal 20px inside `@theme inline`, so cards and panels (`rounded-xl`) never took the squircle size; it now reads a `:root` variable like the others (20px where squircles aren't supported).

**Why:** the user asked for more rounding.

**Tested:** Chrome 154 (`corner-shape` supported): a card's radius reads 44px; screenshot of Today.
