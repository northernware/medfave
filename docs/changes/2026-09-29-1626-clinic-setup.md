# Doctors set up their clinic; licence verification

Opened: 2026-09-29 16:26 PHT · Updated: 2026-09-29 17:00 PHT

## What
- **Set up your practice** on `/welcome` for doctors: name on the PRC
  licence, licence number (7 digits), specialty; clinic name, address, phone.
  Creates the clinic, the doctor (pending), their DOCTOR membership, and a
  starting week: Mon–Fri 9–5, Sat 9–12, lunch 12–1. Email must be confirmed first.
- **Locked until verified** (`lib/auth.ts`, `lib/api.ts`): `requireDoctor`
  and `apiDoctor` refuse an unverified doctor; `requireStaff` refuses any
  member of a clinic with no verified doctor; staff invites refused. Hours,
  breaks, closures, services and clinic details stay open. Home is `/manage`,
  with a status card; a declined doctor sees the reason and sends corrected
  details again.
- **Admin queue** `/admin/verify` (`requirePlatformAdmin`): each pending
  doctor with the automatic checks (email confirmed, licence format, name
  matches the account), a link to the PRC lookup, Verify / Decline + reason.
  Recent decisions below. Admins are emailed on each submission; doctors on
  the outcome.
- **Platform admins** via `npm run admin:grant -- <email> [--revoke]` only.
- **API:** `viewer.verification`; an unverified doctor's `role` is `"none"`.
  `POST /api/v1/practice` and `POST /api/v1/practice/resubmit`, the same rules
  as the web, for the app's setup wizard.
- **Phone-sized web:** the setup form goes one step at a time (You → Your
  clinic), checking each before moving on; a server error opens the step with
  the problem. Wider screens keep one form.
- New forms keep what was typed after an error (`FormState.values`,
  `formValues()`).
- Seeds create their demo doctors verified.
