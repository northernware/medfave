# Clinic setup and verification screens: clearer layout

Opened: 2026-09-29 20:17 PHT

## What
- **Manage, waiting:** a status panel with a 3-step tracker (Clinic set up →
  Licence check → Clinic opens), the licence being checked, and a "While you
  wait" list (hours and services, clinic details). "Who works here" is hidden
  until the clinic opens; the subtitle says it isn't open to patients yet.
- **Manage, declined:** the same tracker with the middle step marked, the
  reason in a red callout, and the resend form laid out properly.
- **Setup form:** numbered sections (1 You, 2 Your clinic), licence number and
  specialty side by side on wide screens, the starting hours as a tinted
  callout, proper padding under the card header.
- **Schedule summary:** runs of days with the same hours are grouped, one per
  line ("Monday to Friday, 9:00 AM to 5:00 PM" / "Saturday, …"). New
  `weekLines()`; `describeWeek()` joins them, so the API summary and other
  pages read better too.
- **Manage header on phones:** brand and sign-out on one row, the sections on
  a scrollable row below, with an "Account" link (the name shows from md up).

## Why
The owner asked to fix the UI of the doctor waiting / verification and clinic
setup screens.

## Tested
- `tsc` and `eslint` pass. Screenshots in headless Chrome at 1280px and
  390px, light and dark, for a new, a pending and a declined doctor.
