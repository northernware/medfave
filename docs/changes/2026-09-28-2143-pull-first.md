# Pull first, before any work and after every merge

Opened: 2026-09-28 21:43 PHT

## What
`AGENTS.md` gains "Before you start: pull first":
- fetch and fast-forward `main`, and branch from it;
- check open PRs and the newest change notes in all three repos;
- for database work, check `migrations/` and `db:verify`, and never `db:update` the shared dev database from unmerged work.

## Why
Requested, so everyone works from the latest `main`. The database rule comes from today: the shared dev database held eight tables (billing, labs, notifications) pushed from a local branch that was never pushed to GitHub. That blocked a planned migration, and nobody else could see the schema.
