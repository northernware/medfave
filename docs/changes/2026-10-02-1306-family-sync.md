# Family: one system, joined to the clinic's charts

Opened: 2026-10-02 13:06 PHT

## What
- `CareLink.familyMemberId`: each chart a login looks after is joined to an entry in that login's family list, the same person on both sides.
  - **Clinic first** (caregiver code, an adult's own grant): the link joins the entry with the same name and birthday, or creates one from the chart. This is done whenever the list is read (`attachLinks` in `lib/family.ts`), which also backfills existing links.
  - **Patient first:** accepting a request for a family member links that exact entry.
- Once linked, the clinic's record is the truth: name, birthday and sex come from the chart. Only "who they are to you" is editable. A linked person can't be removed from the list, only stopped being looked after.
- `GET /family` returns `links`. `PATCH` on a linked person changes only the relationship. `DELETE` on a linked person returns 409. Find a doctor uses the link, not name matching, to find their chart.
- Portal My family uses the links, with **Stop looking after** on linked people.

## Why
The user asked for one system: a record started at the clinic syncs to the patient's family, and one started by the patient syncs to the clinic.
